Часто задавані питання

Для створення нового товару:

  1. Перейдіть до розділу "Прийом"
  2. Натисніть кнопку "Створити новий товар"
  3. Заповніть обов'язкові поля (назва, кількість, ціни)
  4. Додайте штрихкод та фото, якщо потрібно
  5. Натисніть "Створити товар"

Для редагування товару:

  1. Знайдіть товар у списку на сторінці "Товари"
  2. Натисніть на назву товару або кнопку "Редагувати"
  3. Внесіть необхідні зміни
  4. Збережіть зміни кнопкою "Оновити товар"

Для прийому товарів:

  1. Перейдіть до розділу "Прийом"
  2. Додайте існуючі товари або створіть нові
  3. Вкажіть кількість для кожного товару
  4. Заповніть причину прийому
  5. Додайте примітку, якщо потрібно
  6. Підтвердіть операцію

Для видачі товарів:

  1. Перейдіть до розділу "Видача"
  2. Виберіть товари зі списку
  3. Вкажіть кількість для видачі
  4. Заповніть причину видачі
  5. Додайте примітку, якщо потрібно
  6. Підтвердіть операцію
Перевірте наявність товарів перед видачею!

Для імпорту товарів:

  1. Перейдіть до розділу "Інструменти"
  2. Натисніть "Імпорт товарів"
  3. Виберіть файл CSV або Excel
  4. Перегляньте попередній перегляд
  5. Підтвердіть імпорт

Обов'язкові колонки: name, quantity, purchase_price, sale_price

Для експорту товарів:

  1. Перейдіть до розділу "Інструменти"
  2. Виберіть формат експорту (CSV або Excel)
  3. Натисніть відповідну кнопку експорту
  4. Файл автоматично завантажиться

Для створення резервної копії:

  1. Перейдіть до розділу "Інструменти"
  2. Виберіть тип резервної копії:
    • "Резервна копія товарів" — тільки товари
    • "Повна резервна копія" — всі дані
  3. Натисніть відповідну кнопку
  4. Файл автоматично завантажиться

Для генерації звіту:

  1. Перейдіть до розділу "Звіти"
  2. Виберіть тип звіту:
    • Звіт по товарах
    • Звіт по операціях
    • Звіт по змінах
  3. Встановіть фільтри (дата, тип операції тощо)
  4. Натисніть "Згенерувати звіт"
  5. Виберіть формат експорту (PDF або Excel)

При виникненні помилки:

  1. Перевірте правильність введених даних
  2. Переконайтеся, що всі обов'язкові поля заповнені
  3. Спробуйте оновити сторінку (F5)
  4. Якщо помилка повторюється, зверніться до адміністратора

Для захисту даних:

  • Регулярно створюйте резервні копії
  • Зберігайте резервні копії в безпечному місці
  • Не передавайте доступ іншим особам
  • Використовуйте надійний пароль
  • Регулярно змінюйте пароль
