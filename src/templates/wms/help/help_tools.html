Інструменти та утиліти

Імпорт товарів

Призначення: Масове додавання товарів з файлів CSV або Excel.

Підтримувані формати:
  • CSV — текстовий формат, розділений комами
  • Excel — файли .xlsx та .xls
Обов'язкові колонки:
  • name — назва товару
  • quantity — кількість
  • purchase_price — закупівельна ціна
  • sale_price — продажна ціна
Додаткові колонки:
  • barcode — штрихкод
  • category — категорія
  • unit — одиниця виміру
  • description — опис
Перед імпортом ви можете переглянути перші 5 рядків файлу.

Експорт товарів

Призначення: Вивантаження даних про товари в файли для збереження або передачі.

Формати експорту:
CSV формат:
  • Швидкий експорт
  • Малий розмір файлу
  • Сумісний з Excel
Excel формат:
  • Зручне форматування
  • Підтримка кольорів
  • Професійний вигляд
Що експортується:
  • Всі товари в системі
  • Кількість на складі
  • Ціни (закупівельна та продажна)
  • Категорії та штрихкоди
  • Дата створення товару

Резервне копіювання

Призначення: Створення резервних копій даних для захисту від втрати інформації.

Типи резервних копій:
Резервна копія товарів:
  • Тільки дані про товари
  • Швидке створення
  • Малий розмір файлу
Повна резервна копія:
  • Всі дані системи
  • Користувачі та операції
  • Повне відновлення
Формат файлів:
  • JSON — текстовий формат, зручний для читання
  • Автоматичне іменування з датою
  • Можна зберегти локально
Регулярно створюйте резервні копії для захисту даних!

Відновлення даних

Призначення: Відновлення даних з резервних копій у випадку втрати або пошкодження.

Процес відновлення:
  1. Виберіть файл резервної копії
  2. Система перевірить формат файлу
  3. Попередній перегляд даних
  4. Підтвердження відновлення
  5. Автоматичне відновлення
Відновлення перезапише поточні дані! Переконайтеся, що у вас є актуальна резервна копія.

Генератор штрихкодів

Призначення: Створення штрихкодів для товарів у форматі Code 128.

Як використовувати:
  1. Введіть текст або номер
  2. Натисніть "Згенерувати"
  3. Штрихкод з'явиться на екрані
  4. Можна зберегти зображення
Застосування:
  • Створення штрихкодів для нових товарів
  • Друкування етикеток
  • Маркування товарів
