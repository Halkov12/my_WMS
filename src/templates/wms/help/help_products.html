Управління товарами

Перегляд товарів

На сторінці "Товари" ви можете:

  • Переглядати всі товари в системі
  • Шукати товари за назвою або штрихкодом
  • Фільтрувати товари за категорією
  • Бачити загальну статистику (кількість, вартість)

Створення товару

Для створення нового товару:

  1. Перейдіть до розділу "Прийом"
  2. Натисніть "Створити новий товар"
  3. Заповніть обов'язкові поля:
    • Назва товару — обов'язкове поле
    • Кількість — початкова кількість на складі
    • Категорія — для організації товарів
    • Штрихкод — унікальний ідентифікатор
    • Ціни — закупівельна та продажна
    • Фото — зображення товару
  4. Натисніть "Створити товар"

Редагування товару

Для редагування товару:

  1. Знайдіть товар у списку
  2. Натисніть на назву товару або кнопку "Редагувати"
  3. Внесіть необхідні зміни
  4. Збережіть зміни

Категорії товарів

Категорії допомагають організувати товари:

  • Створюйте категорії для групування товарів
  • Використовуйте категорії для фільтрації
  • Категорії відображаються в звітах
Поради
  • ✅ Використовуйте унікальні штрихкоди
  • ✅ Додавайте фото товарів
  • ✅ Правильно вказуйте одиниці виміру
  • ✅ Регулярно оновлюйте ціни
Важливо
  • ⚠️ Назва товару є обов'язковою
  • ⚠️ Кількість не може бути від'ємною
  • ⚠️ Штрихкод повинен бути унікальним
