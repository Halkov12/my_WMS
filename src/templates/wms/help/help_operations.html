Складські операції

Прийом товарів

Призначення: Прийняття товарів на склад від постачальників або повернення товарів.

Як виконати прийом:
  1. Перейдіть до розділу "Прийом"
  2. Додайте існуючі товари або створіть нові
  3. Вкажіть кількість для кожного товару
  4. Заповніть причину прийому (наприклад, "Поставка від постачальника")
  5. Додайте примітку, якщо потрібно
  6. Підтвердіть операцію
При прийомі кількість товарів на складі збільшується.

Видача товарів

Призначення: Видача товарів зі складу клієнтам або для внутрішнього використання.

Як виконати видачу:
  1. Перейдіть до розділу "Видача"
  2. Виберіть товари зі списку
  3. Вкажіть кількість для видачі
  4. Заповніть причину видачі (наприклад, "Продаж клієнту")
  5. Додайте примітку, якщо потрібно
  6. Підтвердіть операцію
При видачі кількість товарів на складі зменшується. Перевірте наявність!

Списання товарів

Призначення: Списання товарів через псування, втрату, закінчення терміну придатності.

Як виконати списання:
  1. Перейдіть до розділу "Списання"
  2. Виберіть товари для списання
  3. Вкажіть кількість для списання
  4. Обов'язково вкажіть причину списання
  5. Додайте детальну примітку
  6. Підтвердіть операцію
Списання незворотне! Товари будуть видалені зі складу.

Історія операцій

Всі операції автоматично записуються в історію:

  • Дата та час операції
  • Тип операції (прийом/видача/списання)
  • Товари та кількості
  • Користувач, який виконав операцію
  • Причина та примітки

Історію можна переглянути в розділі "Звіти" → "Звіт по операціях".
