Звіти та аналітика

Звіт по товарах

Призначення: Детальний звіт по всіх товарах на складі з інформацією про кількість, ціни та вартість.

Що містить звіт:
  • Список всіх товарів
  • Кількість на складі
  • Закупівельна та продажна ціни
  • Загальна вартість товарів
  • Категорії товарів
  • Штрихкоди
Формати експорту:
  • PDF — для друку та збереження
  • Excel — для подальшого аналізу

Звіт по операціях

Призначення: Аналіз руху товарів за певний період з деталізацією по типах операцій.

Що містить звіт:
  • Всі операції за період (прийом, видача, списання)
  • Товари та кількості
  • Дата та час операцій
  • Користувачі, які виконали операції
  • Причини операцій
  • Фільтрація по типах операцій
Фільтри:
  • За періодом (дата початку — дата кінця)
  • За типом операції
  • За користувачем
  • За товаром

Звіт по змінах

Призначення: Історія всіх змін в системі для аудиту та відстеження дій користувачів.

Що відстежується:
  • Створення нових товарів
  • Редагування товарів
  • Всі складські операції
  • Зміни в налаштуваннях
  • Користувач, який зробив зміну
  • Дата та час зміни
Цей звіт допомагає відстежувати хто і коли вніс зміни в систему.

Експорт звітів

Всі звіти можна експортувати в різних форматах:

PDF формат:

  • Зручний для збереження
Excel формат:
  • Для подальшого аналізу
  • Можна редагувати
  • Зручний для обчислень
